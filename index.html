Proving the Unmeasurable

When There's No Number

Metrics cover the numbers. But how do you prove a process happened — a taught greeting, a merchandising reset, a pickup handoff? You make the invisible leave a footprint. Seven ways to make it stick.

Ⅰ

Proof of Completion

The task isn't done until it produces an artifact. Attaching it closes the loop.

Reset → before/after photo uploaded. Handoff → completed checklist, timestamped.
Ⅱ

Manager Sign-Off

A second set of eyes verifies and initials. "I think it's done" becomes "confirmed done."

Friday floor walk; manager signs the merchandising card. No signature, not complete.
Ⅲ

Teach-Back

For taught processes, the person demonstrates the skill — not just that they attended.

After retention training, the associate role-plays the win-back script with a lead.
Ⅳ

Mystery Shop

Random, unannounced checks reveal whether the process holds when no one is watching.

A secret shopper scores greeting and pickup monthly; results feed the board.
Ⅴ

Tie to a Lagging Metric

If a process matters, it eventually moves a number. Let the number be the scoreboard.

"Better pickup" → repeat-rate and pickup NPS. Good process surfaces there within weeks.
Ⅵ

Make it Visible

Public boards create peer accountability. No one wants the empty column on the shared screen.

This board on the breakroom display — completed work, store-vs-store, streaks.
Ⅶ

On-the-Spot Teaching

Catch it in the moment. When you see a process done wrong, coach it right there — don't save it for a review weeks later.

Weak greeting on a floor walk → correct it on the spot, then confirm the fix on the very next customer.
The One Rule

A task is complete only when it leaves a trace someone else can see — a photo, a signature, a demo, an audit score, or a moved number. Build the trace into the task, never into a follow-up meeting.
